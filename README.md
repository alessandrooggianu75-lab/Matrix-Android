# Matrix Android

Salvaschermo Matrix configurabile per Android 16 / Samsung.

## Funzioni
- modalità solo numeri 0–9
- binario 0/1
- esadecimale
- caratteri misti
- velocità, densità, dimensione caratteri e FPS regolabili
- preset Eco, Bilanciato e Massimo
- integrazione Android DreamService

Il workflow GitHub Actions compila automaticamente un APK debug installabile.
